# 🎨 Brand Style Guide: QUANTUN Digital
> **Soluciones Digitales**

![Logo QUANTUN Digital](./Assets/logo_quantun_digital_negro.png)

## 📌 Identidad de Marca
- **Nombre:** QUANTUN Digital
- **Slogan:** Soluciones Digitales

## 🔠 Tipografía

### Tipografía Principal
- **Familia:** `Poppins` (Google Fonts)
- **Uso:** Títulos corporativos, encabezados grandes, y donde se requiera impacto visual.

### Tipografía Secundaria
- **Familia:** `Montserrat`
- **Variantes:** Bold, Regular, Extrabold.
- **Uso:** Cuerpos de texto, descripciones, subtítulos, botones de navegación y lectura fluida.

## 🎨 Paleta de Colores

| Rol | Color | Hex | Muestra | Uso Recomendado |
|-----|-------|-----|---------|-----------------|
| **Principal** | Negro | `#000000` | ⬛ | Fundamental para fondos oscuros, encabezados y textos principales para máximo contraste, dándole un toque premium y elegante. |
| **Secundario** | Verde Lima | `#c9f31d` | 🟩 | Especial para CTAs (Llamados a la acción), botones, hover effects, iconografía puntual y detalles que necesiten un alto nivel de atención por parte del usuario. |
| **Terciario** | Blanco | `#ffffff` | ⬜ | Utilizado para fondos minimalistas, lectura de textos corporativos sobre color principal o espacios de respiro (whitespace). |

*Nota: Para representar fielmente la paleta en código web:*
```css
:root {
  --color-primary: #000000;
  --color-secondary: #c9f31d;
  --color-tertiary: #ffffff;
  --font-primary: 'Poppins', sans-serif;
  --font-secondary: 'Montserrat', sans-serif;
}
```

## 🖼️ Variaciones del Logo (Assets)

En el directorio `/Assets/` se encuentran las versiones oficiales de la identidad gráfica:

1. **Logo Principal Negro** (`logo_quantun_digital_negro.png`):
   Para ser aplicado sobre el color terciario (`#ffffff`) u otros fondos de tonalidad clara.
   
2. **Logo Negativo Blanco** (`logo_quantun_digital_blanco.png`):
   Para ser aplicado sobre el color principal (`#000000`) u otros fondos oscuros.
